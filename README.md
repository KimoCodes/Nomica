# FitFunnel Pro Static Site

Static HTML/CSS project for a fitness coaching landing page with matching client and admin portal mockups.

## Structure
- `index.html` and `styles.css` power the public landing page
- `assets/` stores shared images and video
- `auth/` contains login and registration pages
- `client/` contains the client portal pages and shared portal styles
- `admin/` contains the admin portal pages and shared dashboard styles

## Notes
- This is a static project with demo navigation and placeholder forms
- The login page uses hardcoded demo credentials for routing between the client and admin mockups

## Open Locally
Open `index.html` in a browser, then navigate into the auth, client, or admin sections through the page links.
